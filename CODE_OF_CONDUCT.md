# Code of Conduct

RMD is committed to a welcoming, harassment-free community for everyone,
regardless of background, identity, experience level, or viewpoint.

## Expected behavior

- Be respectful, constructive, and technically specific.
- Welcome questions and differing perspectives.
- Give credit for ideas, code, data, and experimental results.
- Respect privacy and remove sensitive information from reports and logs.

Harassment, personal attacks, discrimination, threats, and publication of
private information are not acceptable.

## Reporting

For ordinary project disputes, contact the maintainers through a GitHub issue
or pull request. Report sensitive conduct or security matters privately through
the repository's GitHub Security reporting workflow. Maintainers may edit,
remove, or reject contributions and participation that violate this policy.
